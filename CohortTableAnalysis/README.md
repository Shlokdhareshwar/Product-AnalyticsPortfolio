# Cohort Analysis Project (SQL + CSV Data)
📌 Overview

This project demonstrates end-to-end cohort analysis using MySQL.
It includes:

Raw synthetic usage dataset (usage.csv)

SQL scripts for:

Data loading

Cohort month & active month extraction

Cohort index computation

Cohort retention matrix generation (CTE + non-CTE versions)

Final retention outputs

This project is designed to help data analysts understand how to track user retention from signup month onwards.
